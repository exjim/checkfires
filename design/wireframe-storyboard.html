앱 구조와 와이어프레임

호스트 앱 안에서 열리는 업체용 소방점검 모듈의 구조입니다. 사용자는 업체의 점검원과 운영자이고, 건물주는 링크로 결과를 열람합니다. 이번 판에서는 등록된 건물을 건축물대장 층별 정보로 불러와 도면 위에서 설비 설치 여부를 켜고 끄는 소방시설 배치 검토(B7)를 건물 관리·점검에 추가했습니다.

1. 앱 구조 (정보 구조)

호스트 앱의 메뉴 하나가 모듈 진입점이 되고, 모듈 안에서는 하단 탭 5개로 이동합니다. 건물주 열람 화면은 모듈 밖의 링크 전용 화면입니다. 파란 배경은 이번에 추가·변경한 화면입니다.

호스트 앱 → 소방안전·점검 (진입점)E1 진입·동의 → E2 업체 선택(소속이 여러 곳일 때) → 마지막으로 본 탭으로 이동

2. 역할과 접근 권한

업체(조직) 단위로 데이터를 분리하고, 같은 업체 안에서 역할로 나눕니다. 점검원은 자신에게 배정된 작업만 보고, 운영자는 업체 전체를 봅니다.

3. 공통 규칙과 화면 상태

내비게이션

  • 탭 안에서는 스택 이동, 뒤로가기는 호스트 규약을 따름
  • 점검 입력 중 이탈 시 임시 저장 후 확인 팝업
  • 알림 딥링크: 작업 상세(J2), 보고서 상세(R2)로 직접 진입

오프라인

  • 상단에 오프라인 배너, 작업·건물 정보는 기기 캐시 사용
  • 대장 스냅샷과 배치도도 캐시에 저장, 설치 on/off 기록은 전송 대기(J7)에 쌓임
  • 전송 충돌 시 서버 기록을 우선하고 점검원에게 알림

빈 상태

  • 작업 없음: "오늘 예정된 작업이 없습니다" + 예정 작업 바로가기
  • 건물 없음(운영자): 건물 등록·일괄 등록 안내
  • 대장 조회 결과 없음: 지번 재확인 또는 층별 정보 직접 입력

오류·권한

  • 소속 업체 없음: 가입 안내 화면(E3)
  • 권한 없는 화면 진입: 이전 화면으로 이동 + 안내
  • 링크 만료: 만료 안내와 업체 연락 방법 표시

증빙 규칙

  • 보수필요·불량은 사진 1장 이상 필수
  • 제출 시 서명, 제출 시각, 점검자 기록 후 잠금
  • 정정은 수정이 아닌 재점검 작업으로 처리

배치 검토 규칙

  • 필수 수량은 대장의 층별 면적·용도와 층고로 계산
  • 핀 윤곽 = 미설치, 채움 = 설치, 눌러서 전환
  • 계산 결과는 참고용, 설계 확정은 전문가·소방서 확인

4. 핵심 흐름

점검원: 하루 점검

호스트 앱 진입→H1 오늘 작업→J2 작업 상세→B7 배치도에서 설비 on/off→J3/J4 설비별 점검→J5 사진→J6 서명·제출→J7 오프라인이면 대기

운영자: 배정과 보고

H2 대시보드→J8 작업 생성·배정→(점검원 수행)→R2 보고서 확인→R3 발송→O1 건물주 열람→O2 확인

운영자: 신규 건물

B1 건물 목록→B5 지번 입력·대장 층별 조회→B7 배치 검토(필수 수량 계산)→B3 설비 확정→B4 계약·주기→J8 첫 작업 자동 생성

5. 화면 와이어프레임

화면마다 역할, 이동 경로, 사용하는 데이터를 적었습니다. 파란 테두리는 추가·변경 화면입니다. 가로로 스크롤해서 보세요. B7은 아래 6번에서 실제로 동작합니다.

6. 소방시설 배치 검토 (B7) · 도면·목록

등록된 건물을 고르거나 지번을 넣고 대장 조회를 누르면 지상·지하 층수, 층별 면적, 층별 용도, 층고가 채워지고, 층마다 필수 설비 수량과 권장 위치가 도면에 나옵니다. 핀이나 목록 항목을 눌러 설치 여부를 켜고 끕니다.

대장 값은 이 화면에서 건축HUB(건축물대장 표제부·층별개요)를 직접 호출하지 못해 샘플 대장 3건으로 채웁니다. 앱에서는 같은 구조의 응답(층별 번호·면적·주용도, 표제부 높이)으로 바꿔 끼우면 됩니다. 층고는 대장에 층별 값이 없어 표제부 높이를 층수로 나눈 값을 처음 값으로 쓰고, 현장 실측으로 고칩니다.
층층별 면적(㎡)층별 용도층고(m)

평면도

경보·감지소화피난 점선 윤곽 = 미설치채움 = 설치 확인옅은 핀 = 권고(법정 아님)

필수 설비와 설치 현황

수량은 화재안전기준(NFTC)의 대표 조항을 단순화한 계산입니다. 실제 대상 여부와 수량은 용도, 구획, 무창층 여부, 지자체 조례에 따라 달라지므로 소방설계 전문가와 관할 소방서 확인이 필요합니다. 처음 표시된 설치 상태는 직전 점검 기록을 흉내 낸 예시입니다.

앱 연동용 응답 (대장 스냅샷 + 배치 결과)

핀 좌표는 도면 가로·세로 대비 0~1 비율입니다. 같은 응답을 건축 도면 위에 겹쳐 그릴 수 있습니다.


  






  
7. 스토리보드 (수정 가능)

  
사용자가 하루 동안 앱을 쓰는 장면을 순서대로 보여줍니다. 장면마다 제목, 상황과 행동, 연결 화면, 메모를 바로 고칠 수 있고, 장면을 복제·삭제·좌우 이동하거나 새로 추가할 수 있습니다. 화면 썸네일은 5번 와이어프레임에서 가져옵니다.
